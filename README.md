# Hamed Gym for Ladies — صفحة هبوط

موقع صفحة واحدة (Single Page) لهوية **Hamed Gym for Ladies**، جاهز للرفع مباشرة على GitHub Pages أو Vercel أو Netlify بدون أي إعداد إضافي (HTML/CSS/JS فقط، لا يحتاج npm install).

## الملفات
- `index.html` — الصفحة كاملة (المحتوى + التصميم + الأكواد)
- `manifest.json` — إعدادات PWA
- `sw.js` — Service Worker للعمل أوفلاين
- `robots.txt` — إعدادات محركات البحث
- `images/products/` — صور المنتجات الحقيقية (9 صور)
- `images/gym/` — صور الجيم الحقيقية (32 صورة)، مستخدمة في قسم "من جوه الجيم" ومعرض الصور

## آخر التحديثات
- تم إصلاح القائمة المنسدلة (الهامبرجر في الموبايل): دلوقتي خلفيتها صلبة بالكامل (مش شفافة) ومتظاهرش فوق كلام الصفحة، وبتتقفل بالزرار أو بالضغط برة أو بزرار Escape.
- تم استبدال أيقونات SVG بصور حقيقية للمنتجات، مع أوصاف وأسعار منقولة من كتالوج الواتساب.
- معرض الصور (Gallery) بقى شغال فعليًا ويعرض الصورة الحقيقية اللي بتدوسي عليها، مع أزرار تنقل بين الصور.
- تمت إضافة قسم تفاعلي جديد "احسبي احتياجك اليومي من السعرات ووزنك المثالي ومقاسك العالمي" فيه حاسبة BMI، حاسبة سعرات، نطاق الوزن الصحي، وحاسبة مقاسات عالمية (US/UK/EU) بناءً على محيط الصدر/الخصر/الأرداف.

## ملاحظة مهمة عن 3 صور منتجات
صور **Mass Gainer General** و **Lipotropic Green Coffee** تم تحديدها بأفضل تخمين ممكن (مطابقة الألوان والسياق) بسبب مشكلة تقنية مؤقتة في عرض الصور أثناء الإعداد — من الأفضل تراجعي صورهم في `images/products/mass-gainer.jpg` و `images/products/lipotropic-green-coffee.jpg` للتأكد إنها مطابقة للمنتج الصح، ولو محتاجة تبديل، تقدري تستبدلي أي صورة بسهولة لأن كل صورة منتج مرتبطة باسم ملف واضح في مصفوفة `PRODUCTS` داخل `index.html`.

## رقم الواتساب
كل أزرار "اشتري الآن" و"تواصلي معنا" مربوطة برقم:
`01221920442` (بصيغة دولية داخل الكود: `201221920442`)

لتغييره مستقبلًا: افتحي `index.html` وابحثي عن السطر:
```js
const WHATSAPP_NUMBER = "201221920442";
```

## إضافة منتج جديد
كل المنتجات موجودة في مصفوفة JS داخل `index.html` باسم `PRODUCTS`، لإضافة منتج جديد:
1. ضيفي صورة المنتج داخل `images/products/`
2. أضيفي كائن (object) جديد بنفس الشكل:
```js
{sku:"CODE-01", name:"اسم المنتج", cat:"بروتين", desc:"وصف المنتج", price:500, oldPrice:600, img:"images/products/اسم-الصورة.jpg", note:"ملاحظة اختيارية زي تفاصيل السعر بالتفصيل"}
```
القيم المتاحة لـ `cat`: `بروتين`, `تخسيس`, `حرق دهون`, `زيادة وزن` (وتقدري تضيفي فئة جديدة وتضيفي زرار فلتر ليها في `filterRow`)
- `oldPrice` و `note` اختياريين — احذفيهم أو سيبيهم فاضيين لو مش محتاجاهم

## النشر على GitHub Pages
1. أنشئي مستودع (repository) جديد على GitHub.
2. ارفعي كل الملفات الموجودة في هذا المجلد.
3. من إعدادات المستودع Settings → Pages، اختاري الفرع `main` والمجلد الجذر `/`.
4. الموقع هيبقى متاح على رابط مثل: `https://username.github.io/repo-name/`

## ملاحظة عن الصور
- صور المنتجات وصور الجيم كلها حقيقية دلوقتي (مش SVG أو أيقونات).
- صور المدربات لسه أيقونات بحروف (Avatar)، لأنه لم يتم توفير صور فعلية للمدربات — لإضافتها استبدلي عنصر الأفاتار بعنصر `<img>` داخل قسم `#trainers`.
- لو عايزة تضيفي صور "قبل وبعد" حقيقية لعميلات (بإذنهم)، ممكن تضيفي قسم جديد بنفس تصميم `.strip-scroll` الموجود في قسم "من جوه الجيم".
